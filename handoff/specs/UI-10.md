# UI-10 — First-run guided tour (user request 2026-09-24)

## Goal
The first time the app opens, a polished guided tour walks a new user through **one complete basic SAM analysis**. It is not a tour of every feature.

## Behaviour
- Starts automatically on first launch, after the main window is shown.
- Every step has **Back**, **Next** and **Skip tour**. Esc also skips, after a short confirm or with an Undo.
- On the first step, or in the final/skip card: a **"Don't show this on startup"** checkbox. It is stored in the existing settings store (QSettings/app settings), never on the network.
- **Help → "Show tour"** replays it any time, whatever the checkbox says. Add a Help menu or Help entry if the shell doesn't have one.
- Show a progress indicator ("Step 3 of 9").
- The tour should survive window resize/move. The highlight follows the target widget.
- If a step's target widget isn't visible (for example, the wrong page), the tour switches to that page first.

## Visual design (make it feel premium)
- A full-window **dimming overlay** (semi-transparent dark) with a **cut-out spotlight** (rounded rectangle, soft edge or glow ring) around the target control.
- The spotlight **animates** between steps (geometry tween, ~300 ms, ease-in-out). The overlay fades in and out (opacity animation).
- A **callout card** (title, 1–3 short sentences in lab terms, not code terms) with an arrow or pointer toward the target. It slides/fades in and places itself automatically so it doesn't cover the target.
- A subtle pulse on the spotlight ring for "click here" steps.
- Welcome and finish cards are centred, larger, with an icon.
- Must use the app's design tokens and theme (light/dark), look right at 100/150/200 % DPI, and honour a reduce-motion setting if one exists.
- Qt only (QPropertyAnimation, QGraphicsOpacityEffect, QPainterPath). No web views, no downloaded assets (offline rule).

## Steps (basic SAM analysis; the agent maps each one to the real widgets)
1. Welcome: what the app does, and that the tour takes about 1 minute.
2. Projects: where your jobs/parts/lots live.
3. New session: create a session in the wizard (the user's own level names).
4. Add image(s): load an SEM image.
5. Set the scale: calibration, auto from metadata or the scale bar; mention the info bar is auto-excluded.
6. Choose **SAM** detection and key settings.
7. Run Analyze: what the progress looks like.
8. Review: grain overlay, filters, removing bad grains.
9. Results: size stats and the ASTM E112 G number.
10. Reports: export to Excel/PowerPoint.
11. Finish: "Replay any time from Help → Show tour".

Tour mode (recommended): **explain-and-point**. The tour highlights and explains; the user may click the highlighted control, and it advances on Next. Optional: for steps 4–7, "Try it with the sample image", using a bundled synthetic demo image if one exists.

## Code / tests
- `ui/tour/` (engine: overlay, spotlight, callout, step model) plus `ui/tour/steps.py` (step definitions as data, targets found by `objectName`). Give target widgets stable objectNames.
- Tests (pytest-qt): starts on first run; doesn't start when "don't show" is set; Help→Show tour starts it regardless; Next/Back/Skip; the overlay is removed after finishing; each step's target resolves; no exceptions on resize.
- Screenshots of 3–4 steps via `ui.demo --capture`.
